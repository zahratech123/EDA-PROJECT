# 📊 Student Performance — Exploratory Data Analysis

## 📌 Project Overview

This project performs **Exploratory Data Analysis (EDA)** on a student performance dataset to understand the factors that may be associated with students' final grades.

The analysis uses **Python, Pandas, Matplotlib, and Seaborn** to clean the dataset, explore relationships between variables, and visualize important patterns.

---

## 🎯 Objectives

* Understand the structure of the student dataset
* Check and handle missing values
* Identify duplicate records
* Analyze numerical and categorical variables
* Study relationships between study habits, attendance, assignments, and final grades
* Create meaningful visualizations
* Identify important patterns and trends in student performance

---

## 📂 Dataset

The dataset contains information related to student academic performance, including variables such as:

* **Study Hours**
* **Attendance**
* **Assignment Score**
* **Final Grade**
* **Gender**
* Other student-related attributes available in the dataset

Dataset file:

`student_data.csv`

## 🔎 Analysis Performed

### 1. Data Loading

The dataset was imported into Python using Pandas.

### 2. Data Cleaning

The dataset was examined for:

* Missing values
* Duplicate records
* Incorrect data types
* Potential outliers

### 3. Statistical Analysis

Descriptive statistics were used to understand the distribution and characteristics of the data.

### 4. Data Visualization

Several visualizations were created, including:

* Scatter plots
* Box plots
* Pair plots
* Distribution plots
* Correlation analysis

### 5. Relationship Analysis

The analysis examines relationships between variables such as:

**Study Hours → Final Grade**

**Attendance → Final Grade**

**Assignment Score → Final Grade**

**Gender → Final Grade**
